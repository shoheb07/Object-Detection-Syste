# Object-Detection-System
The Object Detection System is a computer vision project developed using Python and OpenCV DNN module. The application detects and recognizes multiple objects in real-time using a pretrained MobileNet SSD deep learning mod.

# Object Detection System

## Project Overview

The Object Detection System detects and recognizes multiple objects in real-time using webcam input and deep learning models.

The project uses OpenCV DNN and MobileNet SSD for AI-based object recognition.

# Features

- Real-time object detection
- Deep learning model integration
- Webcam support
- Bounding box visualization


# Technologies Used

- Python
- OpenCV
- MobileNet SSD


# Installation

Install OpenCV:

pip install opencv-python
# Required Files

Download:
- MobileNetSSD_deploy.prototxt
- MobileNetSSD_deploy.caffemodel


# Run Project

python object_detection.py


# How It Works

1. Capture webcam video
2. Load pretrained model
3. Detect objects
4. Draw labels and boxes
5. Display output
